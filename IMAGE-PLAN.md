# Image Plan — Best of Calabria

## Where to get images

**Free sources (Unsplash, Pexels, Pixabay):**
- Search: "Tropea", "Calabria coast", "Scilla Italy", "Aspromonte"
- All royalty-free for commercial use

**Recommended sizes:**
- Hero images: 1920×800px (landscape, wide)
- Card images: 800×600px (4:3 ratio)
- Thumbnails: 600×400px
- Logo: 200×60px (SVG preferred)

## How to add images

1. Go to **WP Admin > Media > Add New**
2. Upload all images
3. For **Featured Images**: Edit page/post > set Featured Image in sidebar
4. For **Hero backgrounds**: Edit page in block editor > click Cover block > replace background
5. For **Homepage hero**: Edit "Home" page > click the Cover block > Media > select image

## Quick start (minimum 5 images needed)

1. Homepage hero (Tropea coast)
2. Tropea card (Santa Maria dell'Isola)
3. Scilla card (Chianalea)
